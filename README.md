# 한국관광 100선 스탬프

「2025-2026 한국관광 100선」 방문 기록용 개인 웹앱(PWA)입니다. 서버나 회원가입 없이, 기록은 사용하는 기기의 브라우저(IndexedDB)에 저장됩니다.

## 실행 방법

Node.js만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
node serve.mjs
```

브라우저에서 http://localhost:5173 을 엽니다.

> `index.html`을 더블클릭해서 열면(`file://`) 데이터 파일을 불러오지 못합니다. 꼭 위 명령으로 실행해 주세요.

## 스마트폰에서 쓰기

- **같은 Wi-Fi에서 잠깐 확인할 때**: PC에서 `node serve.mjs`를 실행하고, 휴대폰에서 `http://<PC의 IP>:5173`으로 접속합니다. 이 방식(http)에서는 홈 화면 설치와 오프라인 기능이 동작하지 않습니다.
- **홈 화면에 앱으로 설치하려면**: 폴더 전체를 HTTPS 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 올린 뒤 휴대폰으로 접속합니다.
  - Android Chrome: 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
  - iPhone Safari: 공유 버튼 → "홈 화면에 추가"

## 기능

- **홈**: 앱을 열면 "이번엔 어디로 떠나 볼까요?" 한 문장과 입력 칸만 보입니다. 가고 싶은 곳, 여행 기간, 출발일, 인원, 출발지를 넣고 버튼 하나를 누릅니다. 가고 싶은 곳을 비워 두면 출발지 주변에서 찾습니다(버튼: '○○' 주변 여행지 추천받기).
- **출발지 지도에서 고르기**: 홈의 🗺 버튼(또는 출발지 목록의 "지도에서 고르기")으로 지도를 열어 가운데 ✚를 출발할 곳에 맞추고 이름(집·회사 등)을 붙여 저장합니다. 주소 검색, 📍 내 위치도 쓸 수 있습니다. 지도는 Leaflet + 오픈스트리트맵(키 필요 없음)이고 열 때만 불러옵니다.
- **블로그 후기 링크**: 상세 화면과 팜플렛에 네이버 블로그(여행 후기·코스·맛집)와 다음·티스토리 블로그 검색 링크 4개가 있습니다. 네이버·다음은 글 목록과 조회수를 앱에 주지 않아(키·서버 필요) 관련도순 검색 결과로 연결합니다.
- **추천 결과**: 목적지 주변(여행 기간이 길수록 넓게, 당일 12km ~ 3박 4일 45km) 여행지를 보여 줍니다. 한국관광 100선은 🏅 100선 표시로 맨 위에, 내가 추가한 곳은 '내 여행지'로 표시합니다.
  - 자료: 앱의 100선·내 여행지 + 한국어 위키백과(위치 검색, '○○시의 관광지' 분류) + 오픈스트리트맵(서버가 응답할 때만). 학교·관공서·박물관 유물·건물 안 작은 문화유산은 걸러 내거나 뒤로 보냅니다.
  - 네이버·구글 검색은 앱에서 직접 부를 수 없어(키·서버 필요) "네이버에서 더 보기", "구글에서 더 보기" 버튼으로 '○○ 가볼만한 곳' 검색을 엽니다.
  - 여행지를 누르면 상세 화면, + 를 누르면 내 일정에 담깁니다. 검색으로 찾은 곳도 상세 설명·가는 방법·팜플렛을 쓸 수 있고, "내 여행지로 저장"하면 방문 기록·메모도 남길 수 있습니다.
- **가는 방법(상세 화면)**: 출발지(홈에서 고른 곳, 지금 위치, 저장한 곳)에서 그곳까지. 같은 내용이 팜플렛 맨 앞 "🧭 가는 방법"에도 들어갑니다(출발지 → 첫 여행지)
  - 🚗 자동차: 오픈스트리트맵 도로망으로 계산한 거리·시간과 주로 지나는 도로(OSRM 공개 서버, 막히는 시간 미반영)
  - 🚌 대중교통: 무료 대중교통 경로 API가 없어 거리로 수단(지하철·시내버스 / 광역·시외버스 / KTX·SRT·고속버스 / 항공 / 여객선)과 대략 시간을 안내하고, 코레일·SRT·고속버스·시외버스 예매 사이트와 네이버 지도 대중교통 길찾기로 연결합니다.
- **목록**: 100곳 전체 목록, 검색, 시·도/분류/방문 상태 필터. 방문한 곳은 선명한 색과 VISITED 스탬프로 표시됩니다.
- **내 여행 일정**: 목록 화면에서 일정(당일치기 / 1박 2일 / 2박 3일 / 3박 4일)과 출발지를 고르고, "+ 목록에서 담기"로 가고 싶은 곳을 누르면 출발지에서 가까운 순서로 일자별로 나눠 보여 줍니다. 상세 화면의 "🧳 내 일정에 담기"로도 담을 수 있습니다. "📄 팜플렛"을 누르면 그 일정 그대로 팜플렛을 만듭니다. 일정에 비해 장소가 많거나 너무 멀면 알려 줍니다. 출발지는 '다음 여행 추천'과 같은 값을 씁니다.
  - 출발지는 주요 도시나 현재 위치 말고도 "🔍 주소"로 집·회사 주소나 장소 이름을 찾아 저장할 수 있습니다(최대 5곳, 오픈스트리트맵 주소 검색). 고른 곳은 "네이버 지도에서 확인"으로 위치를 볼 수 있고, 상세 화면 길찾기에서도 그곳을 출발지로 네이버 지도 앱을 엽니다.
- **여행지 추가**: 목록 맨 아래 "➕ 100선에 없는 여행지 추가"로 이름, 시·도, 시·군·구, 분류, 위치, 설명, 주요 관광 포인트("이름 - 설명" 한 줄에 하나), 특산 음식, 계절, 관람 시간을 넣습니다.
  - 추가한 곳은 100선과 똑같이 방문 기록·사진·맛집 메모·길찾기·일정·추천·팜플렛에 쓰이고, 백업에도 들어갑니다. 진행률의 n/100에는 세지 않고 따로 보여 줍니다.
  - 위치는 "이름으로 위치 찾기"(오픈스트리트맵 검색, 누를 때 한 번만 요청)나 그 자리에서 "지금 여기"로 정합니다. 정하지 않으면 시·도의 대략적인 중심으로 거리를 계산합니다.
  - 저장하면 위키백과에서 설명·사진을 찾아 붙입니다. 직접 적은 설명이 있으면 그것을 먼저 씁니다.
- **상세 · 기록**: 방문일, 별점(1~5), 메모, 사진 최대 5장. 사진은 긴 변 1280px로 줄여서 저장합니다.
- **여행 정보**: 관광지마다 주요 관광 포인트와 특산·향토 음식을 보여 줍니다. 음식 이름을 누르면 그 지역에서 파는 곳을 네이버지도로 찾습니다.
- **맛집·숙소 찾기**: 특정 가게를 추천하지 않고, 네이버지도·카카오맵의 "○○ 맛집/숙소" 검색으로 연결해 최신 리뷰와 별점을 보게 합니다.
- **내 맛집·숙소 메모**: 이름, 메모, 지도 링크(선택)를 관광지별로 저장합니다. 백업에도 포함됩니다.
- **다음 여행 추천**: 일정(당일치기 / 1박 2일 / 2박 3일 / 3박 4일), 계절(현재 달로 자동 선택), 출발지(주요 도시 또는 현재 위치)를 고르면, 아직 안 간 곳을 가까운 곳끼리 묶어 일자별 코스 3개를 보여 줍니다.
  - 점수 기준: 추천 계절(제철인 곳 가산, 철 지난 곳 감점), 출발지에서의 이동 시간(짧은 일정은 가까운 곳, 긴 일정은 먼 곳 우대), 일정 대비 볼거리 양
  - 제주는 항공 이동으로 1박 2일 이상, 울릉도는 여객선 이동으로 2박 3일 이상일 때만 추천합니다. 한라산처럼 오래 걸리는 곳은 오가는 날이 아닌 중간 날에 배치합니다.
  - 이동 시간은 직선거리 × 1.3 ÷ 시속 70km로 추정한 값이라 실제와 다를 수 있습니다.
- **여행 팜플렛**: 추천 코스 카드나 관광지 상세 화면의 "📄 팜플렛 만들기"로, 함께 갈 사람에게 보낼 HTML 파일 한 장을 만듭니다.
  - 입력: 여행 제목, 출발일(넣으면 일자별 날짜·요일 표시), 함께 가는 사람, 한마디, 내 맛집·숙소 메모 포함 여부
  - 내용: 일자별 일정, 관광지별 대표 사진·소개, 주요 관광 포인트(찾은 곳은 사진·설명), 특산 음식, 맛집·숙소(내 메모 + 네이버·카카오 검색 링크), 준비물 체크리스트(계절·항공·여객선·산행에 맞춤)
  - 사진·설명: 한국어 위키백과에서 자동으로 찾고 출처를 표시합니다. 설정에 한국관광공사 TourAPI 인증키(data.go.kr에서 무료 발급)를 넣으면 공식 자료를 먼저 씁니다. 이름이 같은 다른 문서를 넣지 않도록 지역 이름으로 확인하므로, 못 찾은 포인트는 이름만 나옵니다. 사진은 인터넷에 연결돼 있을 때 보입니다.
  - 맛집·숙소는 평점 순위를 자동으로 매기지 않습니다(네이버·카카오가 평점을 공개 API로 주지 않음). 지도 앱에서 리뷰 많은순·별점순으로 정렬해 고르도록 안내합니다.
  - 공유하기: 휴대폰에서 파일 공유를 지원하면 카카오톡 등으로 바로 보내고, 아니면 파일로 내려받습니다. 받는 사람은 앱 없이 브라우저로 열 수 있고, 인쇄용 레이아웃도 들어 있습니다.
  - 예시: `examples/pamphlet-example.html`
- **진행률**: 전체 n/100, 시·도별 달성률, 추가한 여행지 방문 수, 최근 방문 5곳
- **설정**: 정보 업데이트(앱 새 버전 확인, 관광지 설명·사진·좌표 새로 받기), JSON 백업 내보내기/가져오기(병합·덮어쓰기), 테마(시스템/라이트/다크), 전체 기록 삭제

### 정보는 언제 바뀌나요

- 관광지 목록(`places.json`)과 볼거리·향토 음식(`guide.json`)은 앱에 들어 있는 고정 데이터라 자동으로 바뀌지 않습니다. 저장소에서 파일을 고쳐 푸시하면 반영되고, 설정의 "앱 새 버전 확인"으로 바로 받을 수 있습니다.
- 설명·사진·정확한 위치는 설정의 "관광지 정보 새로 받기"를 누를 때만 위키백과(또는 TourAPI)에서 받아 이 기기에 저장합니다. 받은 좌표가 기존 대략 위치에서 30km 넘게 떨어지면 쓰지 않습니다. 받은 좌표는 내 주변 관광지, 길찾기, 추천에 쓰입니다.
- 팜플렛 사진·설명과 지도·맛집·숙소 링크는 쓸 때마다 최신 자료를 불러옵니다.

## 관광지 데이터(`data/places.json`) 수정하기

- **이름**은 한국관광공사 공식 지도 PDF의 표기를 그대로 옮겼습니다.
- **시·도와 시·군·구**는 PDF에 텍스트로 들어 있지 않아 따로 붙였습니다. 권역별 개수는 언론 보도와 일치합니다. 여러 시·군에 걸친 곳(예: 설악산국립공원 "속초시 외")은 앱에서 "확인 필요"로 표시합니다.
- **분류**(자연/역사/문화/도시/레저)는 공식 분류가 아니라 필터용으로 붙인 값입니다.
- **설명과 위도·경도**는 비어 있어서(`null`) 앱에서 "확인 필요"로 표시됩니다. 값을 채운 뒤 `unverified` 배열에서 해당 항목을 빼면 표시가 사라집니다.

```json
{"id":"p004","name":"남이섬","sido":"강원","sigungu":"춘천시","category":"자연",
 "description":"북한강의 섬, 메타세쿼이아길로 유명","lat":37.79,"lng":127.52,"unverified":[]}
```

`id`는 방문 기록과 연결되는 키이므로 바꾸지 마세요.

## 여행 정보(`data/guide.json`) 수정하기

관광지 `id`별로 `q`(지도 검색어), `points`(관광 포인트), `foods`(특산 음식)를 적습니다. 공식 자료가 아니라 일반적으로 알려진 정보로 작성했으니, 틀린 곳이 있으면 이 파일을 고치면 됩니다.

```json
"p004": {"q":"남이섬","points":["메타세쿼이아길","송파은행나무길"],"foods":["춘천 닭갈비","춘천 막국수"]}
```

`foods`가 빈 배열이면 "대표 향토 음식 정보가 없어요"로 표시됩니다. 지금은 서울 등 7곳이 비어 있습니다.

추천 기능에 쓰는 값도 같은 파일에 있습니다.

- `seasons`: 추천 계절 (예: `["봄","가을"]`, 사계절이면 네 개 모두)
- `hours`: 둘러보는 데 걸리는 대략 시간
- `area`: 거리 계산용 대략 위치 `[위도, 경도]` (정확한 좌표가 아님)
- `island`: 울릉도처럼 배로만 갈 수 있는 곳은 `"ulleung"`

## 2단계 확장을 위한 구조

- **지도 · 주변 추천**: `places.json`의 `lat`/`lng`를 채우면 바로 쓸 수 있습니다.
- **배지/업적**: 방문 기록(`visits`)과 `sido`만으로 계산할 수 있습니다.
- **클라우드 동기화**: 방문 기록마다 `updatedAt`이 있어 병합 기준으로 쓸 수 있습니다. 백업 가져오기의 "병합"도 이 값을 사용합니다.
